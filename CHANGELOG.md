# 1.0.0
- Initial release: secondary variant properties that do not affect the selectability of the other properties
- Variant switch keeps primary values and selects the first available secondary value
- Hide or grey out non-matching secondary values (configurable per sales channel)
- Secondary values are excluded from the product search and the listing filter (configurable)
- Variant switch respects the core setting to hide sold-out closeout products
- Supports `ProductConfiguratorLoader::loadFromCombinations()` (Shopware 6.7.15+)
